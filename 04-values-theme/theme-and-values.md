# تقنيات الثيم والقيم (Theme & Values)

## أولًا: لا تسرق الثيم — ابنِ هوية

RoK ثيمها: **حضارات تاريخية متعددة في خريطة فانتازيا-تاريخية واحدة**.  
نجاحها مش bas فقط؛ نجاحها **وضوح القيم + Spectacle الحرب + Progression يومي**.

لعبتك لازم تجاوب:
1. إحنا مين؟
2. بنحارب ليه؟
3. شكل المجد عندنا إيه؟
4. إيه اللي يخلي التحالف "بيت" مش بس ديسكورد؟

---

## تقنيات بناء الثيم (Theme Crafting Techniques)

### 1) Pillar Fantasy (جملة واحدة)
أمثلة:
- "ثمانية أقاليم… ممر واحد قد يغيّر مملكة"
- "التحالف أقوى من التاج"
- "من الواحة إلى العرش"

اكتب جملة Fantasy واربط بيها: UI، الموسيقى، أسماء المناطق، الأحداث.

### 2) Visual Bible
- لوحة ألوان Zone1/2/3 مختلفة
- Zone3 له إضاءة/طقس مميز (عاصفة، شفق، أعمدة نور)
- الحضارات تتشارك العالم لكن تختلف في city skin والجنود

### 3) Naming System
 snappy + قابل للترجمة:
- Regions, Passes, Altars, Commanders
- عربي فصيح مبسّط أو عربي-فانتازي إن كان الجمهور عربي

### 4) Audio Identity
- طبول حرب عند Rally
- جرس/بوق عند سقوط Pass
- موسيقى هادئة داخل المدينة، أخطر على الخريطة

### 5) Ceremony Moments
لحظات لازم تتحوّل لـ screenshot:
- أول احتلال Pass
- دخول Zone2
- كسر Final Gate
- تثبيت العرش في Zone3
- تتويج التحالف نهاية الموسم

### 6) UI Storytelling
- خريطة استراتيجية تلوّن الأقاليم حسب السيطرة
- Timeline موسمي في الشاشة الرئيسية
- ألقاب: حارس الممر، قاهر التصفية، والي الإقليم...

## القيم (Player Values) — ماذا نكافئ؟

| قيمة | كيف تظهر في اللعب | كيف نكافئها |
|------|-------------------|-------------|
| **التنظيم** | Rally timings, pass control | نقاط موسم + ألقاب قيادة |
| **الولاء للتحالف** | helps, garrison, donations | Alliance gifts, tech |
| **المثابرة اليومية** | gather, train, quests | Battle pass, chests |
| **المهارة** | counters, commander pairing | تقارير + فوز outnumbered محدود |
| **الاستكشاف** | scouting, map knowledge | Intel markers, AP efficiency |
| **الندّية** | underdog holds | مكافآت دفاع ناجح |
| **الاحترام/السلامة** | anti-toxicity tools | mute/report + moderation |

### قيم يجب الحذر منها
- "ادفع لتربح فقط" → يقتل المجتمع
- "لا قيمة لغير التوب 10" → churn
- "الصفر أو العرش" بدون أهداف ثانوية → إحباط

## Loop القيم عبر الـ Zones

### Zone1
قيم: النمو، الجوار، الانضمام، أول انتصارات صغيرة  
Hero moment: احتلال أول Pass

### Zone2
قيم: التنسيق واسع النطاق، لوجستيات، تضحيات المستشفى  
Hero moment: تثبيت Shrine تحت ضغط

### Zone3
قيم: التصفية، البطولة الجماعية، الإرث  
Hero moment: Hold العرش دقائق حاسمة / دفاع أخير

## تقنيات تثمين الإحساس (Feel Tech)

1. **Juice:** اهتزاز خفيف، flash، رقم قتل واضح
2. **Readable combat:** counters مفهومة في التقرير
3. **Loss aversion العادل:** wounded تُشفى، مش كل موت دائم
4. **Social proof:** إعلانات الخريطة (Pass taken, Core contested)
5. **Ritual login:** دخول يومي له معنى (AP, VIP, quests, season track)
6. **Progress pillows:** حتى الخسارة تعطي XP/نقاط مشاركة

## هوية مقترحة لمشروعك (ROK2 working title)

### خيار A — ثيم عربي فانتازي
- 8 أقاليم بأسماء عربية
- Zone3: "عرش الممالك" أو "قبة الفلك"
- قيم: المروءة، الحلف، حماية القوافل

### خيار B — تاريخ بديل عالمي
- حضارات متعددة (مثل الفئة)
- Zone3: Lost Temple / Sun Spire
- قيم: المجد الحضاري

### خيار C — فانتازيا خالصة
- عناصر / تنانين / بلورات
- Zone3: Crystal Heart
- قيم: السيطرة على المصدر

**توصية:** A أو B مع Map structure الذي ثبّتناه (8/expand/finals) لأنه تميز هيكلي واضح.
