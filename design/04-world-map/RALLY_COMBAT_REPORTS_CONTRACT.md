# عقد تقارير الراليات والقتال الموسّع

**الحالة:** عقد تنفيذي.
**المالك:** الخادم السلطوي في `KingdomShard`.
**النطاق:** تقارير القتال ضد الممرات والعرش وأهداف القلب والبرابرة، مع طبقة تفصيلية للراليات.

## الهدف

يعطي التقرير اللاعب نتيجة قابلة للتدقيق بعد انتهاء القتال، من دون أن يحسب العميل خسائر أو مكافآت أو أهلية. يُظهر تقرير الرالي مساهمة كل مشارك، وما عاد من قواته، وتقسيم إصاباته، وأي أثر سلطوي قابل للعرض مثل خبرة القائد أو نقاط الموسم. لا تُنشأ مكافأة أو خسارة بمجرد فتح الواجهة.

| المجال | قاعدة العقد |
|---|---|
| المصدر | يحل الخادم القتال، ويوزّع نتائج قوات الرالي نسبياً وفق القوات التي التزم بها كل مشارك، ثم يحفظ التقرير بعد تسجيل المستشفى والنتائج النهائية. |
| هوية التقرير | يحمل كل تقرير `id` ووقت الإنشاء ونوع الهدف والفائز ونتيجة المهاجم والمدافع. يحمل تقرير الرالي أيضاً `rallyId` والتحالف والقائد وقائمة المشاركين. |
| المشاركون | لكل مشارك: القوات الملتزم بها، الناجون، إجمالي الخسائر، القتلى، الجرحى الشديدون والخفيفون، وما قبلته المستشفى إن وُجد. |
| المكافآت | لا يعرض العميل مكافآت تقديرية. يعرض فقط `commanderXp` أو `seasonPoints` أو مكافأة أول احتلال حين يسجلها الخادم فعلاً. |
| الوصول | يحصل اللاعب على قائمة تقاريره من مسار مصادق عليه. يرى صاحب الهجوم تقريره الفردي؛ ويرى عضو التحالف تقرير رالي تحالفه، من دون كشف رالي تحالف آخر. لا تحمل لقطة العالم العامة تفاصيل التقارير. |
| البث الحي | يرسل الخادم تقريراً حياً فقط للاعب المهاجم أو لاعبي تحالف الرالي المسموح لهم. تبقى القائمة المصادق عليها مرجع التعافي عند فتح الواجهة لاحقاً. |
| العرض | تبقى شاشة تقارير القتال نقطة الدخول الرئيسية. تعرض الصفوف شارة رالي وعدد المشاركين، وتعرض التفاصيل جدول مساهمة المشاركين وخسائرهم ومكافآت التقرير. |

> **قاعدة حتمية:** القوات المدمجة في الرالي ليست ملكاً للقائد. عند العودة، يعيد الخادم الناجين إلى مالكيهم الأصليين بعد تسوية الخسائر والإصابات، ولا يجوز للعميل تعديل هذه الأرصدة.

## واجهات الخادم

| المسار أو الحدث | الغرض | البيانات الرئيسية |
|---|---|---|
| `GET /v1/combat/reports` | استعادة آخر التقارير المسموح للاعب رؤيتها | قائمة تقارير مُصفّاة بحسب اللاعب والتحالف الموثقين |
| `battle_report` | تحديث حي محدود بالمستلمين المصرح لهم | تقرير كامل قابل للعرض |
| `rally` في التقرير | كتلة اختيارية عند وصول مسيرة متولدة من رالي | الرالي والتحالف والقائد والمشاركون ونتائجهم |
| `rewards` في التقرير | مكافآت سجلها الخادم | خبرة قائد، نقاط موسم، أو مكافأة أول احتلال |

## حالات العرض

| الحالة | واجهة القائمة | لوحة التفاصيل |
|---|---|---|
| تقرير عادي | النتيجة ونوع المعركة والوقت | القوى، خسائر الطرفين، المستشفى والمكافآت |
| رالي قيد المعالجة | لا يظهر كتقرير حتى يحسم القتال | لا توجد نتائج جزئية أو خسائر تقديرية |
| رالي محسوم | شارة رالي وعدد المشاركين والنتيجة | بطاقة إجمالية ثم جدول مشاركين ثم المكافآت السلطوية |
| عدم وجود تقارير | رسالة إرشادية غير قابلة للضغط | لا توجد بطاقة فارغة أو أرقام صفرية مضللة |

## معايير القبول

1. يحفظ التقرير بعد احتساب المستشفى والمكافآت النهائية، لا قبلها.
2. يوزع الخادم خسائر الرالي وناجيه لكل مشارك بصورة حتمية وبلا تجاوز لقواته الملتزم بها.
3. يعيد مسار عودة الرالي الناجين إلى أصحابهم، لا إلى القائد وحده.
4. لا يستطيع لاعب خارج التحالف أو خارج المشاركين استرداد تقرير رالي آخر عبر الطلب أو البث.
5. تعرض واجهة Unreal شارة الرالي، والمشاركين وخسائرهم، والمكافآت المسجلة من الخادم، وتُحدّث عند وصول التقرير أو عند فتحها.
6. يغطي اختبار العقد المسار الموثق، والتصفية السلطوية، وتوزيع العائدين، وحقول واجهة التقرير.
