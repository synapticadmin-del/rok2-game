# P7-T3 — رحلة لاعبين من البداية إلى الممر

> **الغرض:** توثيق سيناريو قبول تشغيلي يربط تأسيس المدينة والتحالف والرالي والممر وتقارير القتال وقصة الموسم، مع فصل ما يستطيع اختبار HTTP إثباته عن التحقق المرئي الإلزامي داخل عميل Unreal Engine 5.4.4.

## حدود الدليل

اختبار HTTP لا يثبت صحة الرسم أو الصوت أو RTL أو حركة الكاميرا داخل Unreal. لذلك يقسم هذا البند إلى دليل خادمي متكرر، ودورة قبول بشرية قصيرة داخل المحرر. لا يدّعي أي منهما أنه بديل للآخر.

| المستوى | الأداة | ما يثبته |
|---|---|---|
| تكاملي سريع | `e2e_p7_t3_player_journey.mjs` | التأسيس، المصادقة، لقطات العالم، التحالف، إنشاء الرالي، الانضمام، الاسترجاع من HTTP، والملكية الأساسية |
| تكاملي كامل | `WAIT_FOR_RALLY=1` مع المشغّل نفسه | إطلاق الرالي بعد مهلة الخادم، المسيرة الموحدة، تقريري المشاركين، أثر القصة الموسمية، وعودة القوات بلا خطأ قاعدة بيانات |
| قبول عميل | خطتا UE 5.4.4 أو PIE مستقلان | FTUE المرئي، واجهات التحالف والرالي، أيقونة المسيرة، التقرير، القصة، وإعادة الاتصال |

## السيناريو الخادمي

يلعب **Alpha** بروما و**Bravo** بالصين. يؤسس كل منهما مدينة، ثم ينضم Bravo إلى تحالف Alpha. يمنح التشغيل التجريبي قوات واضحة للحالة فقط عبر مسار المدير؛ لا يتغير أي منطق توازن أو اقتصاد. ينشئ Alpha رالياً على ممر مفتوح وينضم Bravo بقوات مستقلة. بعد ذلك يعيد المشغّل قراءة قائمة الراليات برمز Bravo نفسه، ليثبت أن حالة الانضمام مصدرها الخادم وليست حالة واجهة عابرة.

| # | المرحلة | دليل النجاح الأساسي |
|---|---|---|
| 1 | الصحة والخصوصية | الخادم صحي، و`/v1/world/snapshot` يرفض الطلب بلا رمز |
| 2 | FTUE | رمزا ضيف صالحان ومدينتان مميزتان في لقطة عالم مشتركة |
| 3 | التحالف | تحالف واحد يضم Alpha وBravo ويعيده مسار العضوية |
| 4 | الرالي | رالي ممر في حالة `forming` ويظهر لـBravo قبل الانضمام |
| 5 | المشاركة | يسجل الخادم مساهمتي Alpha وBravo منفصلتين |
| 6 | إعادة فتح الجلسة | قائمة الراليات بعد إعادة القراءة تؤكد `isJoined=true` و`participants=2` بلا تكرار |
| 7 | الوضع الكامل فقط | الرالي يصبح `launched`، يسجل مسيرة موحدة، ويظهر تقرير القتال لكلا المشاركين مع حدث قصة ممر |

## التشغيل المحلي

شغّل Worker محلياً في طرفية، بعد تطبيق ترحيلات D1 المحلية كما هو موضح في دليل [البناء والتشغيل](BUILD_AND_PIE.md). لا توجد قيمة افتراضية لمفتاح المدير.

```bash
cd game/backend
npx wrangler d1 migrations apply rok2-db --local
npx wrangler dev
```

في طرفية ثانية، شغّل المسار السريع. وهو لا ينتظر مدة تجمّع الرالي، ولذلك يصلح كتأكيد سريع للعقود أثناء التطوير.

```bash
cd game/backend
ADMIN_KEY=... npm run test:e2e-p7-t3
```

شغّل المسار الكامل عندما تتوفر نافذة اختبار تتسع لمهلة تجمّع الرالي المضبوطة خادمياً. لا يخفض المشغّل المهلة أو يتجاوز سلطة الخادم.

```bash
cd game/backend
WAIT_FOR_RALLY=1 ADMIN_KEY=... npm run test:e2e-p7-t3
```

يمكن توجيه الأمر إلى نشر مصرح به عبر `BASE_URL`. استخدم بيئة اختبار مخصصة فقط، لأن المشغّل ينشئ لاعبين وتحالفاً ورالياً تجريبيين.

```bash
cd game/backend
BASE_URL=https://your-approved-test-host ADMIN_KEY=... npm run test:e2e-p7-t3
```

## قبول العميل في UE 5.4.4

نفّذ هذا الجزء بعد مرور بوابة P7-T2 على جهاز Windows. افتح عميلين مستقلين أو جلستين PIE، ولا تستخدم محرراً واحداً كدليل على التزامن بين عميلين.

| # | الإجراء | المتوقع بصرياً وتشغيلياً |
|---|---|---|
| 1 | افتح العميلين كأسلوب ضيف واختر حضارتين مختلفتين | تظهر FTUE وهوية الحضارة ولا تتوقف الواجهة عند التأسيس |
| 2 | أسس المدينتين وافتح خريطة العالم | المدينتان والعناصر المسموح بها حسب التكبير تظهران في الجلستين |
| 3 | أنشئ تحالفاً ثم انضم إليه من العميل الثاني | تتحدث قائمة التحالف من الخادم ولا تكرر العضو |
| 4 | أنشئ رالياً على ممر وانضم من العميل الثاني | تظهر بطاقة الرالي والعداد وحالة الانضمام بوضوح |
| 5 | انتظر الإطلاق ثم تابع المسيرة | تظهر المسيرة المتحركة وأيقونة الممر في الجلستين |
| 6 | افتح التقرير عند وصول الرالي | يقرأ كل مشارك تقريره، بخسائر وعناصر رالي من دون تسريب للاعب غير مشارك |
| 7 | افتح حكاية المملكة | يظهر حدث فتح/احتلال الممر ضمن الخط الزمني في الواجهة |
| 8 | افصل الشبكة من العميل الثاني ثم أعدها | تعود شارة الاتصال، ثم قائمة الراليات والمدينة والقصة بلا actors أو عدادات مكررة |

## حالة القبول

نجح المسار الكامل محلياً على Worker وD1 المعزولين، مثبتاً إنشاء الرالي وإطلاقه ووصول التقرير لكلا المشاركين وأثر القصة وعودة القوات. يبقى P7-T3 في حالة **WIP** إلى أن يمر المسار الخادمي الكامل على بيئة اختبار مصرح بها، ثم تمر دورة العميل في UE 5.4.4. لا يغلق التحقق البنيوي أو المسار السريع وحده البند.
