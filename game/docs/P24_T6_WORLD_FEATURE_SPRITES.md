## 2. التقطيع

`scripts/slice_world_feature_sprites.py` يقطّع بـ**مركّبات الشفافية المتصلة**
(8-connectivity على قناة alpha) لا بشبكة ثابتة، ومصادره مشتقّة من جذر المستودع:

```python
REPO = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
SRC_DIR = os.path.join(REPO, "game", "client-unreal", "Content", "Art", "WorldMapIcons")
```

### المعايير — ثوابت مسمّاة قابلة للفحص

```python
ALPHA_THRESHOLD = 24        # لا 0: الحواف المصفّاة تترك هالة تصل المركّبات
MIN_SPRITE_AREA = 900       # النص 180–210 بكسل · أصغر جسم حقيقي 5120
FRAGMENT_AREA_RATIO = 0.30
PAD = 6
```

### المعيار الذي احتاج قياساً لا تخميناً

استبعاد كل ما يلمس الحافة كان يحذف **عقدتين حقيقيتين**: معسكر الأخشاب ومنجم
الذهب يصلان الحدّ الأيمن في صفيحة الموارد تماماً. فالمعيار مزدوج — يلمس الحافة
**وهو** أصغر من 30% من الجسم الرئيسي:

| الحالة | النسبة |
|---|---|
| قصاصة المنجم | 1412 / 21084 = **6.7%** |
| قصاصة الممر | 2233 / 28241 = **7.9%** |
| قصاصة المعبد | 3190 / 20426 = **15.6%** |
| عقدة حقيقية | 5120 / 6674 = **77%** |

هامش واسع بين 15.6% و77%، فالحدّ 30% ليس رقماً مختاراً بالذوق.

### قصّ المستطيل وحده لا يكفي

النص يقع على بعد 2 بكسل تحت قاعدة العقدة، فأي هامش يعيده. فالقصّ يُطمس **بقناع
المركّب نفسه**:

```python
window = labels[y0:y1, x0:x1] == comp["label"]
pixels[:, :, 3] = (pixels[:, :, 3] * (np.array(mask) / 255.0)).astype(np.uint8)
```

الشفافية **تُضرب** بالقناع لا تُستبدل به: الضرب يحفظ تدرّج الحواف المصفّاة،
والاستبدال يُنتج حدوداً مسنّنة.

### ترتيب الأسماء مكاني بالمركز لا بالحدّ الأعلى

معسكر الأخشاب يبدأ عند `y=8` وحقل القمح عند `y=33`، وهما في الصف نفسه بصرياً
(الأشجار أعلى من السنابل). الترتيب بالحدّ الأعلى كان يضعهما في صفّين **ويقلب
الاسمين**. المراكز 64.5 و70.5 متجاورة، والصف الثاني عند 168 و171.

### الناتج

11 معلماً × 3 خرائط (D/N/E) = **33 أصلاً**، مع `sprites.json` يسجّل إحداثيات كل
قصّ ومعاييره فالمراجعة لا تحتاج إعادة تشغيل. وخرائط N/E تُقصّ **بنفس
الإحداثيات من صفائحها** لا تُعاد توليداً، فلا يضيع أصلها.

## 3. الوصل

```cpp
FString URok2ArtAssets::WorldFeatureIdForNode(const FString& NodeKind, int32 Level)
```

يترجم نوع العقدة الخادمي (`FRok2NodeEntity::Kind`) إلى معلم، **والمستوى يرفع
الرسم إلى نسخته الأوفى**:

| النوع | ≤ 3 | ≥ 4 |
|---|---|---|
| `gold` | `gold_mine` | `gold_mine_large` |
| `barb` | `barbarian_camp` | `barbarian_keep` |

فيقرأ اللاعب تراتب العقدة من شكلها لا من رقم وحده. والممر والعرش لهما
`pass_fortress` و`throne_temple`.

### ثلاث طبقات احتياط

```
الرسم المقطّع  ←  أيقونة icon_node_* المسطّحة  ←  الشكل الهندسي
```

غياب الحزمة لا يُعطّل الخريطة، وهو نفس نمط الاحتياط الذي أرسته P7-T10.

### الحجم قرار بصري لا رقم مثبَّت

```cpp
UPROPERTY(EditAnywhere, Category = "Rok2|World Features")
float WorldFeatureSpriteScale = 1.8f;
```

الأصلان ليسا من عائلة واحدة: أيقونة `icon_node_*` رمز مسطّح 512×512 يُقرأ من
بعيد، والرسم المقطّع منظر isometric بتفصيل داخلي (منجم بعربة وسكة، معسكر بخيام
ونار) عرضه 106–256 بكسل — فبنفس المقياس يصير تفصيله بقعة. القيمة النهائية
تُقرّر في قبول PIE (P24-T7)؛ تثبيتها من غير رؤية ادّعاء.

## 4. عطل في سكربت الاستيراد، حُسم بالناتج

`-run=ImportAssets` يعيد **exit 1** ويسجّل:

```
LogAutomatedImport: Error: Invalid Destination Path (): FilenameToLongPackageName failed to convert ''.
```

حتى عندما يستورد الملفات الـ33 كلها بنجاح — يقرأ الـcommandlet مجموعة فارغة
إضافية من إعداداته الافتراضية إلى جانب `ImportGroups`. ولهذا لا يفحص أيٌّ من
سكربتات الاستيراد القائمة في المشروع شفرة الخروج.

لكن تجاهلها بلا بديل يعني فشلاً حقيقياً يمرّ صامتاً. فالبوابة صارت **عدّ أصول
`.uasset` الناتجة**:

```powershell
$Assets = @(Get-ChildItem $FeatureDir -Filter 'T_feat_*.uasset')
if ($Assets.Count -ne $Sprites.Count) { throw ... }
```

والسكربت يشغّل التقطيع بنفسه قبل الاستيراد، وإلا بقي تعديل المعايير بلا أثر حتى
يتذكّر أحدهم تشغيله يدوياً — فيُستورد أصلٌ قديم ويُظنّ أنه الجديد.

## 7. التحفّظ الصريح

**لا قبول PIE.** لم يُرَ أي معلم على الخريطة في اللعبة، ولا حُكم على
`WorldFeatureSpriteScale`، ولا اختُبر أثر 33 نسيجاً جديداً على ميزانية P7-T6
(يُقاس في P24-T8).

**معلمان مقطّعان ومستوردان لكن غير موصولَين عن قصد:** `holy_shrine` ينتظر مواقع
مقدسة في لقطة العميل (الخادم يملك `holy_sites.json` لكن `FRok2WorldSnapshot` لا
يحمل مواقع)، و`mountain_ridge` زخرفة تضاريس لا كيان في اللقطة. وصل ما لا مصدر
بيانات له كان سيُنتج معلماً في موضع **مخترع** — وهو ما تمنعه AGENTS.md §3.

**صور `Events` الأربع** بقيت مؤجّلة إلى مركز الأحداث (P20-T1): لوحات مشهد لا
معالم خريطة، ولا شاشة تستهلكها بعد.
