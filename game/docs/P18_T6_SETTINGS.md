## 1. ما كان مكسوراً

### أ. دالتان معرّفتان منذ P7-T7 بلا مستدعٍ

`URok2Accessibility::SetUiScale` و`SetHighContrast` موجودتان منذ P7-T7،
و`grep` عليهما في المشروع كله لا يجد **أي موضع استدعاء**. النتيجة: مقياس
الواجهة 1.0 دائماً والتباين العالي مطفأ دائماً، وكل ما بُني عليهما يعمل على
قيمة ثابتة لا سبيل للاعب إلى تغييرها:

- `ScaledSize` / `ScaledIconSize` / `GetScaledPx` — في عشرات المواضع.
- `AccessibleTextFor` / `IsHighContrast` — طبقة الألوان المعتمدة على التباين.
- `URok2Typography::SizeOf` تضرب في `GetUiScale` — أي أن سلم الخطوط كله معلّق
  على رقم لا يتغيّر.

### ب. الصوت رقم واحد

```cpp
float MasterVolume = 0.8f;
bool  bAudioEnabled = true;
```

حقلان عامّان لا شاشة تلمسهما، **ولا فصل بين الموسيقى والمؤثرات**. فلا سبيل
لخفض الموسيقى وحدها — وهي أول ما يخفضه لاعب في مكان عام.

### ج. لا تخزين

لا `USaveGame` للإعدادات ولا `GConfig`. أي تغيير (لو أمكن) يضيع بإغلاق التطبيق.

## 2. القرارات

### مستويان يُضربان في العام

```cpp
float GetEffectiveMusicVolume() const { return FMath::Clamp(MasterVolume * MusicVolume, 0.f, 1.f); }
```

`MasterVolume` يبقى «الحدّ الأعلى العام» فتبقى كل الاستدعاءات القائمة صحيحة، ولا
حاجة لتعديل كل موضع يقرأه.

و`SetMusicVolume` تطبّق على الموسيقى **العاملة الآن**:

```cpp
if (MusicComponent) MusicComponent->SetVolumeMultiplier(GetEffectiveMusicVolume());
```

بلا هذا لم يكن يُسمع أثر الشريح حتى تُعاد الموسيقى — وقاعدة التجربة #6 تطلب
رد فعل فوري (<100ms).

### مقياس Slate إلى جانب رمز المشروع

```cpp
void URok2Accessibility::SetUiScale(float NewScale)
{
    UiScale = FMath::Clamp(NewScale, 0.85f, 1.6f);
    if (FSlateApplication::IsInitialized())
    {
        FSlateApplication::Get().SetApplicationScale(UiScale);
    }
    OnAccessibilityChanged.Broadcast();
}
```

`UiScale` يُقرأ **وقت البناء** فقط (كل `GetScaledPx` في كل `SetSize`/`SetPosition`)،
فالودجات القائمة لا تتأثر حتى تُعاد. مقياس Slate يكبّر كل ما هو معروض فوراً —
بما فيه لوحة الإعدادات نفسها، فيرى اللاعب أثر الشريح وهو يحرّكه. والودجات
الجديدة تُبنى على الرمز نفسه فتبقى متسقة.

حدود الشريح في الشاشة (`UiScaleMin = 0.85f`, `UiScaleMax = 1.6f`) تطابق حرفياً
ما يقصّه الـsetter — شريحٌ يسمح بما يُقصّ يُري اللاعب قيمةً لا تُطبَّق.

### الحفظ في وحدة قابلية الوصول لا في الشاشة

`URok2Accessibility::SaveSettings()` و`LoadAndApplySavedSettings()`. مصدر
الحقيقة واحد: من يستدعي الـsetter يحصل على الحفظ، فلا حالة في الذاكرة تخالف
القرص.

والاستعادة تمرّ **بالـsetters** لا بإسناد الحقول:

```cpp
SetUiScale(Save->UiScale);
SetHighContrast(Save->bHighContrast);
```

الإسناد المباشر كان سيحمّل القيم بلا أن يسري مقياس Slate ولا الصوت العامل.

### `URok2SettingsSaveGame` بلا معرّف لاعب

تفضيلات **جهاز** لا حالة لعب. `URok2CityLayoutSaveGame` يُربط بمعرّف اللاعب لأنه
حالة لعب؛ الصوت والمقياس والتباين ليسا كذلك — ومن يشارك جهازاً يشارك مقياس
الواجهة، وهذا المتوقّع.

وAGENTS.md §3 «الخادم هو السلطة» لا يُخالف: لا رقم توازن ولا مورد ولا نتيجة
قتال في هذا الملف.

### الاستعادة قبل بناء أي ودجة

```cpp
void ARok2GameMode::BeginPlay()
{
    Super::BeginPlay();
    if (URok2Accessibility* A11y = URok2Accessibility::Get())
    {
        A11y->LoadAndApplySavedSettings();
    }
    // ... ثم الـApi والممثلون وشاشة الدخول
```

المقياس يُقرأ وقت البناء، فاستعادته بعد إنشاء شاشة الدخول والـHUD كانت ستتركهما
على 1.0 حتى يُعاد بناؤهما — أي أن الإعداد المحفوظ **لا يُرى في الجلسة التي
يُحمَّل فيها**.

### لا زر «تطبيق»

كل تغيير يسري فوراً ويُحفظ لحظتها. ضبط الصوت والحجم يحتاج سماعاً ورؤيةً
فورية، وأي حالة معلّقة تعني أن اللاعب يضبط رقماً لا يسمعه. وضبط المؤثرات يُشغّل
نموذجاً مسموعاً بالمستوى الجديد، وإلا ضبط اللاعب رقماً بلا مرجع.

### موضع الزر: الشريط العلوي لا العنقود

عنقود الأزرار الدائرية أسفل يمين لأفعال اللعب (بناء/قادة/تحالف/حقيبة/أحداث/
حضارة/بحث) وقد امتلأ بسبعة. والشريط العلوي لحالة اللعبة وأدواتها — وهناك
يتوقّع اللاعب الإعدادات، بجوار الجرس.

الترتيب في المنفذ **58**: فوق اللوحات (50) وتحت طبقة الإرشاد (60) — الإعدادات
تعلو ما تضبط شكله، ولا تحجب بطاقة الإرشاد.

### الشرائح ومربعات الاختيار من نظام التصميم

`USlider` بنمطه الافتراضي يرسم مسار Slate الرمادي ومقبضاً دائرياً أبيض —
غريبان تماماً وسط برونز وذهب. المسار من `Rok2Surface::ProgressTrack()` نفسه
الذي يرسم أشرطة تقدّم الطوابير، والمقبض `Rok2Surface::Circle(Gold)`.

ومربع الاختيار بحالاته الست، والحالة المحدّدة تحمل **حشواً ذهبياً ونصاً** لا
علامة صحّ وحدها (§8.3). وكل شريح يحمل قيمته رقماً: نسبة مئوية للصوت، مضاعف
للمقياس (`×1.25`).

`Rok2VisualTheme.cpp` بمعادلة الإضاءة النسبية:

