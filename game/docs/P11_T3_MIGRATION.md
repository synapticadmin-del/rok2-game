# P11-T3 — هجرة الممالك إلى Lost Kingdom

## الفكرة

بعد يوم 50 من الموسم تُفتح خريطة Lost Kingdom (Z4–Z7). كل لاعب مؤهل يستطيع الهجرة إليها لنقل معركته إلى مسرح KvK. الهجرة مقيدة بشروط صارمة لأن نقل لاعب بين مملكتين يغير توازن القوة.

## المتطلبات

| الشرط | القيمة |
|---|---|
| مستوى قاعة المدينة | 16+ |
| المسيرات النشطة | لا يوجد أي مسيرة متحركة أو عائدة للاعب |
| القيادة في Rally | غير مسموح بالقادة الحالية (يُفحص عند إنشاء rally) |
| حماية المخزن | المخزن محمي 48 ساعة بعد الهجرة (vault_protected_until) |
| Cooldown | 30 يومًا بين هجرتين |
| التكلفة | 5,000 gems (تُخصم سلطويًا من D1) |

## السلوك السلطوي

الخصم والنافذة تُنفذ على D1: `UPDATE cities SET gems=gems-5000 WHERE gems>=5000` — ضمان عدم السحب السلبي. نافذة الحماية 48 ساعة تُسجل في `vault_protected_until` حتى لا يُهاجم مخزن اللاعب المهاجر مباشرة.

## رفض الهجرة

| السبب | رمز الخطأ |
|---|---|
| قاعة المدينة منخفضة | city_hall_too_low |
| مسيرات نشطة | active_marches |
| cooldown لم ينته | migration_cooldown |
| gems غير كافية | insufficient_gems |
