# نظام الواجهات والتجربة (UI/UX Design System)

> **المبدأ الحاكم:** اللعبة يجب أن **تُشاهَد** قبل أن تُقرأ. كل عنصر واجهة يخدم العالم المرئي — ولا يستبدله.
>
> **المرجعية البصرية:** `assets/ui-city-mockup.png` — موكاب شاشة المدينة المستهدفة.

---

## 1. الهوية البصرية للواجهة

| العنصر | المواصفة |
|--------|----------|
| الأسلوب | برونز داكن + ذهب مزخرف، إطارات مشطوفة بمسامير، زخارف gothic خفيفة — طابع «مخطوطة ملكية» |
| الخطوط | عنوان: خط عربي فخم (Cairo Black / Aref Ruqaa للعناوين الكبرى) · أرقام/إنجليزي: Trajan-style serif أو Cinzel |
| لوحة الألوان | خلفية لوحات `#1A120B` شبه شفافة · إطار ذهبي `#C9A227` · نص عاجي `#F5E9D0` · خطر `#A93226` · نجاح `#3E7C4F` |
| الأزرار الرئيسية | دائرية مزخرفة (ليست مستطيلة) — شعور «ختم ملكي» |
| الحركة | كل لوحة تنزلق من أسفل كـ Bottom Sheet · كل تأكيد له وميض ذهبي · لا قفزات جامدة |

## 2. خريطة الشاشات

```
شاشة التحميل (Boot)
   └─ اختيار الحضارة (بطاقات كبيرة بفن كامل، ليست قائمة نصية)
        └─ شاشة المدينة (الافتراضية — العالم الحي)
             ├─ لوحة المبنى (Bottom Sheet — تفتح بلمس أي مبنى)
             ├─ شاشة القادة (بطاقات بورتريه + تفاصيل)
             ├─ شاشة البحث (شجرة مرئية)
             ├─ شاشة التحالف
             ├─ الحانة (فتح صناديق بأنيميشن)
             ├─ المتجر / VIP / Battle Pass
             └─ خريطة العالم (Zoom متصل من المدينة)
                  ├─ لوحة الهدف المحدد (عقدة/ممر/مدينة عدو)
                  ├─ لوحة إطلاق المسيرة (اختيار قوات + قائدين)
                  ├─ تقارير القتال (بطاقات + تفاصيل خسائر)
                  └─ لوحة الموقع المقدس (عداد السيطرة + باف)
```

## 3. شاشة المدينة — HUD التفصيلي

### 3.1 الشريط العلوي (Resource Bar)
- من اليمين لليسار (RTL): 🍞 طعام · 🪵 خشب · 🪨 حجر · 🪙 ذهب · 💎 gems · ⚡ AP.
- أرقام مختصرة (1.2M) + شريط ممتلئ خفيف تحت كل مورد (نسبة للسعة).
- لمس مورد → لوحة مصادره ومصارفه (Breakdown).
- لمس gems → المتجر. لمس AP → شراء/استخدام جرعات.

### 3.2 الوسط = المدينة الحية
- المدينة السداسية تملأ الشاشة — تتحرك فيها حياة: عمال، جنود يتدربون، دخان مداخن، فقاعات موارد فوق المباني المنتِجة.
- لمس مبنى → **بطاقة المبنى** (Bottom Sheet):
  - صورة المبنى بثيم الحضارة + مستواه.
  - زر رئيسي واحد واضح: «ترقية إلى L{n}» (التكلفة والوقت).
  - زر ثانوي حسب النوع: «تدريب» (ثكنة) · «شفاء» (مستشفى) · «بحث» (أكاديمية) · «فتح صناديق» (حانة).
  - طابور حالي بشريط تقدم.

### 3.3 أسفل يمين — زر البناء الرئيسي
- زر دائري كبير (🔨) — شارة حمراء عند وجود بنّاء خامل.
- يفتح قائمة البناء: شبكة أيقونات مبانٍ بثلاث فئات (اقتصاد/عسكري/زخرفة) — تُسحب مباشرة إلى المدينة.
- حوله أزرار دائرية أصغر: القادة (خوذة) · التحالف (درع) · الحقيبة (كيس) · الأحداث (راية).

### 3.4 أسفل يسار — الدردشة والبريد
- فقاعة دردشة مصغرة (سطران آخر رسائل) تتوسع عند اللمس: تبويبات مملكة/تحالف/خاص.
- أيقونة بريد فوقها بشارة غير المقروء.

### 3.5 اليسار — المهام
- لوحة مهام قابلة للطي: المهمة الرئيسية الحالية + زر «اذهب» (ينقل الكاميرا ويبرز الهدف بإطار ذهبي نابض).

### 3.6 أعلى يمين — الحالة
- شارة اتصال (خضراء/حمراء) · يوم الموسم · مؤقّت فتح المنطقة القادمة · جرس إشعارات بعدّاد.

## 4. خريطة العالم — HUD

- نفس الشريط العلوي (استمرارية بصرية).
- **Zoom متصل:** قرصة واحدة: مدينة ↔ إقليم ↔ عالم. عتبات تكبير تبدّل مستوى التفصيل (LOD) — لا شاشات منفصلة.
- لمس هدف (عقدة مورد/ممر/معسكر برابرة/مدينة لاعب) → **بطاقة هدف** سفلية:
  - اسم + مستوى + مالك + موارد متبقية/حامية.
  - أزرار: «جمع» · «هجوم» · «Rally» (R3+) · «استكشاف» · «إحداثيات».
- **لوحة إطلاق المسيرة:** شريط سفلي كامل — اختيار وحدتين بسلايدرز كميات، اختيار قائد أساسي + ثانوي (بورتريهات دائرية)، زمن الوصول المحسوب، زر إطلاق كبير.
- المسيرات الجارية: أيقونات متحركة على الخريطة + شريط زمن وصول؛ لمسها → تفاصيل + زر استدعاء.
- فلتر طبقات: أيقونات (مدن/موارد/برابرة/مواقع مقدسة/تحالفي).

---

## 5. شاشة القادة

- قائمة: شبكة بطاقات بورتريه (مملوكين ملونين، غير المملوكين رماديين مع تقدم المنحوتات 34/60).
- تفاصيل القائد:
  - بورتريه كبير + نجوم (6) + شريط XP + أيقونات تخصصاته الثلاثة ملونة.
  - 5 خانات مهارات: الأولى نشطة (توهج)، الباقي سلبية — لمسها يفتح وصفها + ترقيتها بالمنحوتات.
  - زر المواهب → 3 أشجار ملونة (أحمر/أصفر/أزرق) بنقاط قابلة للتوزيع + إعادة تعيين.
  - 6 خانات معدات + إكسسوار — لمسها للتصنيع/التبديل.
  - زر «تعيين في تشكيلة» — يحدد زوج المسيرة.

---

## 6. شاشة اختيار الحضارة (أول انطباع!)

- **ليست قائمة** — بطاقات عرض كاملة الشاشة تُقلَب أفقياً (carousel):
  - فن المدينة الكامل للحضارة (من `assets/civ-*-city.png`).
  - اسم الحضارة + فانتازيها بجملة.
  - 3 بونصات بأيقونات + الوحدة الخاصة بصورتها + قائد البداية ببورتريه.
- زر تأكيد ذهبي كبير: «أُقسم الولاء لـ {الحضارة}».

---

## 7. التقارير والإشعارات

- تقرير قتال = **بطاقة معركة** مصغرة: صفّا القوات، القائدان، النتيجة (نصر/هزيمة بلون)، خسائر مقسمة (قتلى/خطير/خفيف) بأشرطة، زر تفاصيل.
- إشعار داخل اللعبة: بطاقة تنزلق من الأعلى بأيقونة الحدث + تتلاشى — ولا توقف اللعب أبداً.
- مركز إشعارات قابل للطي يحتفظ بآخر 20 حدثاً.

---

## 8. قواعد تجربة صارمة

1. **كل إجراء ≤ 3 لمسات** من شاشة المدينة.
2. **لا نص بدون أيقونة** في أي زر رئيسي.
3. **لا لون خارج اللوحة** — حتى أرقام الضرر (أحمر) والشفاء (أخضر).
4. **الحالة دائماً مرئية في العالم** قبل اللوحات: مبنى يُبنى = سقالات، جرحى = صليب نابض، مورد جاهز = فقاعة.
5. **كل شاشة تعمل بيد واحدة** على الهاتف (الأزرار الرئيسية في الثلث السفلي الأيمن RTL).
6. زمن استجابة اللمس: رد فعل بصري فوري (<100ms) حتى لو النتيجة من الخادم لاحقاً (تفاؤلية UI).

## 9. التنفيذ في UMG (UE5)

```
Widgets/
  WBP_HUD_Resources      — الشريط العلوي
  WBP_CityHUD            — أزرار المدينة (بناء/قادة/تحالف/حقيبة/دردشة/مهام)
  WBP_BuildingCard       — بطاقة المبنى (Bottom Sheet)
  WBP_BuildMenu          — شبكة البناء بفئاتها
  WBP_CommanderList/Card — شاشة القادة
  WBP_MarchLaunch        — لوحة إطلاق المسيرة
  WBP_TargetCard         — بطاقة الهدف على الخريطة
  WBP_BattleReport       — بطاقة تقرير القتال
  WBP_CivSelect          — كاروسيل الحضارات
  WBP_ToastCenter        — إشعارات
```

- كل لوحة تُبنى كـ UMG Widget Blueprint فوق الطبقة الحية (المدينة/الخريطة) — لا شاشات منفصلة بخلفية سوداء.
- أنيميشن اللوحات عبر UMG Animations (Slide/Fade) — معيار موحد 0.25s ease-out.

| لمس زر | نقرة خشبية خفيفة |
