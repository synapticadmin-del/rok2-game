# القلعة السداسية والبناء الحر (Hex Castle & Free-Form City)

> **الهدف:** مدينة اللاعب ليست قائمة مبانٍ — بل **قلعة حية داخل سور سداسي**، يضع اللاعب مبانيه فيها ويحرّكها بحرية كاملة، تماماً كما في Rise of Kingdoms.
>
> **المرجعية البصرية:** `assets/hex-castle-layout.png` — الشكل المستهدف.

---

## 1. لماذا سداسي؟

- الشكل السداسي يعطي المدينة **هوية بصرية فورية** على الخريطة — تُعرف من أول نظرة.
- شبكة hex تعطي **6 اتجاهات** لوضع المباني بدل 4 — تخطيطات أكثر عضوية وأقل «شبكة إكسل».
- في UE5: تمثيل الشبكة بـ **axial coordinates (q, r)** — حسابات بسيطة وسريعة.

## 2. بنية المدينة

### 2.1 الطبقات المكانية

```
┌─────────────────────────────────────┐
│  السور السداسي (Hex Wall) — ثابت    │  ← 6 أضلاع، مستوى = متانة
│  ┌───────────────────────────────┐  │
│  │  منطقة البناء الحرة           │  │  ← شبكة hex داخلية
│  │   ┌────┐                      │  │
│  │   │قلعة│  مبانٍ حرة التموضع   │  │
│  │   └────┘  (City Hall مركزي)   │  │
│  │        طرق حجرية اختيارية     │  │
│  └───────────────────────────────┘  │
│  بوابة رئيسية (ضلع واحد) + أبراج    │
└─────────────────────────────────────┘
```

### 2.2 المكونات الثابتة (لا تُنقل)

| العنصر | الوصف |
|--------|-------|
| **Hex Wall** | 6 أضلاع حجرية + بوابة رئيسية على ضلع واحد + برجان عند البوابة. متانته = HP السور من الخادم. عند مستويات أعلى يكتسب أبراجاً إضافية وزخارف (أعلام، مشاعل) |
| **City Hall** | يُزرع تلقائياً في الخلية المركزية (0,0) عند تأسيس المدينة. أكبر مبنى وأكثرها تفصيلاً لكل حضارة |
| **مخارج البوابة** | طريق حجري من البوابة نحو خارج المدينة (للمسيرات الخارجة) |

### 2.3 شبكة البناء الحر

- الشبكة الداخلية: **~90–120 خلية hex قابلة للبناء** (تتسع مع مستوى City Hall — تكبر المدينة بصرياً كل 5 مستويات).
- كل مبنى له **بصمة hex** خاصة:

| الحجم | الأبنية | الخلايا |
|-------|---------|---------|
| صغير (1 خلية) | Farm, Lumber Mill, Quarry, Goldmine, Storehouse, Courier, Watchtower, Scout Camp, Shop, Monument | 1 |
| وسط (7 خلايا — زهرة hex) | Barracks, Stable, Archery Range, Siege Workshop, Hospital, Academy, Tavern, Trading Post, Alliance Center, Builder's Hut | 7 |
| كبير (12 خلية) | Castle, City Hall | 12 |

## 3. وضع التحرير (City Editor) — UX

### 3.1 الدخول والخروج
- زر «تحرير المدينة» (مطرقة + فرشاة) في HUD المدينة → يدخل وضع التحرير: الكاميرا تبتعد قليلاً، الشبكة تظهر بخفوت، المباني تُبرَز بإطار ذهبي.

### 3.2 الإجراءات
| الإجراء | السلوك |
|---------|--------|
| **سحب مبنى** | المبنى يصبح شبحاً (ghost) بشفافية 60% + إطار أخضر/أحمر حسب صلاحية الموضع. الخلايا المشغولة والمحظورة تُظلَّل |
| **تدوير** | زر تدوير أو إيماءة — المباني ذات الاتجاه (حظائر، أسواق) تدور بزوايا 60° |
| **إعادة للمخزن** | أي مبنى يمكن «طيّه» لمخزن جانبي مؤقت ثم إعادة وضعه — لا يُفقد أبداً |
| **حفظ/تحميل تخطيط** | 3 خانات تخطيط محفوظة: «عسكري»، «إنتاج»، «حر». تبديل فوري بأنيميشن انزلاق المباني |
| **إلغاء/تأكيد** | التعديلات تُحفظ محلياً فوراً وتُرسل للخادم دفعة واحدة عند الخروج (endpoint واحد) |

### 3.3 قواعد الصلاحية
- لا تراكب بين بصمات المباني.
- كل المباني يجب أن تلمس خلية داخل السور.
- City Hall والسور ثابتان دائماً.
- **التخطيط لا يؤثر إطلاقاً على القوة أو الدفاع** — حرية تجميلية خالصة (قرار RoK الأصلي، يمنع «التخطيط الإلزامي الأمثل»).

| الحالة | المظهر |
|--------|--------|
| قيد البناء | هيكل خشبي سقالات + عمال صغار يتحركون + شريط تقدم دائري فوقه |
| مكتمل مستوى 1 | المبنى الأساسي بثيم الحضارة |

| تدريب جارٍ | أعلام تتحرك فوق الثكنة + عداد جنود |
| جرحى موجودون | أيقونة صليب أحمر نابضة فوق المستشفى |

## 5. السور والدفاع

- **متانة السور** (من الخادم): تُعرض كشريط أخضر→أحمر عند الاقتراب من السور.
- عند اختراق السور في هجوم: المدينة تشتعل بصرياً (نار ودخان) — إن نفدت المتانة **تنتقل المدينة تلقائياً** لموقع عشوائي (قاعدة RoK).
- الإصلاح يدوي (موارد + وقت) أو gems للإطفاء الفوري.
- السور ثابت هندسياً — ترقيته تغيّر مظهره (حجر → حجر محصّن → أبراج إضافية + بوابة ذهبية).

## 7. التنفيذ التقني (UE5)

### 7.1 بنية الكود المقترحة

```
Rok2/Public/City/
  Rok2HexGrid.h          — axial coordinates، تحويل world↔hex، بحث الجوار
  Rok2CityLayoutActor.h  — يدير السور + الشبكة + توليد المدينة
  Rok2BuildingActor.h    — مبنى واحد (بصمة، حالة، أنيميشن، تفاعل)
  Rok2CityEditorMode.h   — وضع التحرير (سحب/إفلات/تدوير/شبح)
  Rok2HexWallActor.h     — السور السداسي (6 أضلاع، متانة، مظهر بالمستوى)
Rok2/Private/City/ (التنفيذ)
```

### 7.2 البيانات
- `data/city_layout.json` (جديد — مخطط): بصمة كل مبنى، حد أقصى لكل نوع، خلايا الشبكة لكل مستوى City Hall.
- تخطيط اللاعب يُخزن على الخادم: `{ buildingId, q, r, rotation }[]` — endpoint: `POST /v1/city/layout` (يُضاف للـ backend).

### 7.3 شبكة Hex (axial)
```cpp
// world -> hex
q = (sqrt(3)/3 * x - 1/3 * y) / size
r = (2/3 * y) / size
// hex -> world
x = size * sqrt(3) * (q + r/2)
y = size * 3/2 * r
```
السور السداسي = كل الخلايا (q,r) حيث `max(|q|,|r|,|q+r|) == R` (نصف قطر المدينة).
