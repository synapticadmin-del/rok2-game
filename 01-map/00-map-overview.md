# نظام الخريطة — نظرة عامة (Zone Architecture)

## الرؤية التي طلبتها (الأساس)

الخريطة **متقسمة لـ 3 Zones** بتدرج صعوبة وسيطرة ونهاية موسم:

```
┌─────────────────────────────────────────────────────────────┐
│                        ZONE 1 (البداية)                      │
│   8 مناطق (Provinces/Regions) مفصولة بجبال + ممرات (Passes) │
│   كل مملكة/تحالفات تبدأ وتتوسع هنا                          │
├─────────────────────────────────────────────────────────────┤
│                        ZONE 2 (التوسع)                       │
│   عدد مناطق وسطى (4–6 مقترح) + أهداف أقوى                   │
│   صراع بين الممالك القوية                                   │
├─────────────────────────────────────────────────────────────┤
│                     ZONE 3 (التصفية / النهاية)               │
│   منطقة واحدة مركزية — الـ Finals / King of the Hill          │
│   فيها الهدف الأعظم (Throne / Lost Temple / Crystal Core)   │
└─────────────────────────────────────────────────────────────┘
```

هذا قريب فلسفيًا من:
- **Home Kingdom map** (RoK العادي): مناطق + Passes + Lost Temple في الوسط
- **Lost Kingdom / KvK maps**: طبقات/محافظات + ممرات بمستويات + مركز للحسم

لكن **تصميمك أوضح وأصرح**: Zone1 = 8 أقاليم، Zone2 = توسع، Zone3 = تصفية واحدة.

---

## المصطلحات

| المصطلح | المعنى |
|---------|--------|
| **Zone** | طبقة كبرى على الخريطة (1 / 2 / 3) |
| **Region / Province** | منطقة داخل Zone (مثلاً 8 في Zone1) |
| **Mountain Range** | حاجز طبيعي غير قابل للعبور |
| **Pass (ممر)** | بوابة قابلة للاحتلال بين منطقتين/Zones |
| **Holy Site / Altar / Sanctum** | نقاط قوة إقليمية تعطي بافات |
| **Throne / Core / Lost Temple** | الهدف المركزي في Zone3 |
| **Territory** | أرض تحالف متصلة عبر Flags/Forts |
| **March** | مسيرة جيش من نقطة لنقطة بزمن |

---

## قواعد الحركة الأساسية

1. **الجبال = Wall طبيعي**: المسيرات لا تعبرها.
2. **العبور الوحيد بين الأقاليم = Pass محتل** (بتحالفك أو ائتلافك).
3. **لا تليبورت داخل نصف قطر حماية الممر** (Anti-teleport cheese).
4. **Zone أعلى = مكافآت أعلى + صعوبة أعلى + خطر أعلى**.
5. **Zone3 تفتح متأخر** (بعد شروط/وقت موسم) عشان التصفية تبقى نهاية مش بداية.

---

## تدفق الحرب النموذجي (Season Flow)

```
الأسبوع 1–2:  سيطرة داخل Zone1 (8 مناطق)
الأسبوع 3–4:  فتح ممرات Zone1→Zone2 + صراع Zone2
الأسبوع 5–6:  تثبيت Zone2 + تجهيز التصفية
الأسبوع 7–8:  فتح Zone3 + تصفية نهائية + ترتيب الممالك/التحالفات
```

(الأرقام قابلة للضبط حسب طول الموسم)

---

## ليه التصميم ده قوي؟

| الميزة | الفائدة |
|--------|---------|
| 8 مناطق في Zone1 | توزيع لاعبين عادل + حروب محلية مبكرة |
| جبال + ممرات | Chokepoints = مهارة تنظيم مش بس أرقام |
| Zone2 | يفرز التحالفات القوية |
| Zone3 واحدة | لحظة ذروة واضحة (Spectacle) + بث/محتوى |
| تدرج | لاعب جديد مش بيتسحق في اليوم الأول في القلب |
