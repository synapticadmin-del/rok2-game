# Zone 1 — ثماني مناطق البداية (Home Ring)

## الهدف التصميمي
Zone 1 هي **حاضنة النمو + حروب الجيران**.  
فيها **8 مناطق** متساوية نسبيًا، مفصولة **سلاسل جبال**، ومترابطة فقط عبر **Passes**.

---

## الشكل العام (Octant / Ring)

تخيّل الخريطة كدائرة/مثمن حول المركز:

```
                 N
            R2        R3
        R1                R4
      W                      E
        R8                R5
            R7        R6
                 S

       (الداخل باتجاه Zone2/Zone3)
```

- كل `R1..R8` = Region
- بين كل Region والتانية: **Mountain wall + 1–2 Passes**
- الحافة الخارجية: حدود العالم / محيط / جبال خارجية (اختياري)
- الحافة الداخلية: ممرات نحو **Zone 2**

## ماذا يوجد داخل كل Region؟

### 1) Spawn / Starter Sectors
- شبكة نقاط ولادة موزعة
- **Safe bubble** مؤقت للجدد (اختياري: 24–72 ساعة حماية أو منطقة تدريب)
- كثافة Barbarians منخفضة→متوسطة

### 2) Resource Nodes (على الخريطة)
| النوع | مستويات مقترحة في Z1 | ملاحظات |
|-------|----------------------|---------|
| Food node | 1–4 | الأكثر شيوعًا |
| Wood node | 1–4 | |
| Stone node | 1–3 | أقل من food/wood |
| Gold node | 1–3 | نادر نسبيًا |
| Gem node | نادر جدًا / أحداث | |

### 3) Holy Sites الإقليمية (Altars / Sanctums)
كل Region فيها **1 Altar رئيسي** + اختياريًا مواقع أصغر.

أنواع بافات (من روح أنظمة RoK):
- Flame → Attack
- Earth → Defense
- Harvest → Gathering
- Wisdom → Research / XP
- Storm → March speed
- Surge → Skill damage / combat specialty

**قواعد الاحتلال (مقترح مستوحى من اللعبة):**
- يفتح للسيطرة كل X أيام
- لازم تحتفظ به مدة (مثلاً 2–4 ساعات) لتثبيت الملكية
- بافات نفس النوع لا تتكدس بلا حدود
- القتال عندها يولّد wounded/dead حسب نوع الموقع

### 4) Passes داخل Zone1
- **Border Passes**: بين R و R المجاورة (8–16 ممر)
- مستوى الممر في Z1: **Lv1–Lv3**
- يحتاج Rally/تنظيم لاحتلاله
- بعد الاحتلال: تحالفك يعبر + يمد Territory

### 5) Alliance expansion slots
- أماكن موصى بها لـ Alliance Fortress/Flag
- يمنع البناء العشوائي اللي يكسّر القراءة البصرية للماب

## الجبال في Zone1

### الوظيفة
1. **فصل الأقاليم** (منع blitz من أي اتجاه)
2. **خلق Chokepoints** عند الممرات
3. **توجيه التوسع** للداخل (نحو Zone2) بدل الفوضى

### قواعد تقنية
```text
tile.terrain = mountain => blocked = true
pathfinding avoids mountains
only Pass cells connect region graphs
```

### قراءة اللاعب
- الجبل لازم يكون واضح بصريًا من الزوم البعيد
- الممر يلمح بلون/أيقونة/مستوى
- Strategic view يعرض Regions + Pass owners

---

## قواعد اللعب في Zone1

1. **البداية:** اللاعب يتولد في Region حسب مملكة/توزيع السيرفر.
2. **الهدف المبكر:** بناء مدينة + جمع + Barbarians + الانضمام لتحالف.
3. **الهدف المتوسط:** احتلال Passات محلية + Altar الإقليم.
4. **الهدف المتقدم داخل Z1:** توحيد عدة Regions تحت ائتلاف/مملكة قبل فتح Z2.
5. **ممنوع دخول Z2** قبل:
   - وقت السيرفر (Season timer)، أو
   - احتلال Inner Pass(es) بمستوى معين، أو
   - الاثنين معًا (مُفضّل).

---

## توازن السكان (Population Balance)

لو السيرفر = 8 ممالك:
- كل مملكة → Region واحدة في Z1 (مثالي)
- لو عدد الممالك مختلف: وزّع 2 ممالك/Region أو العكس مع matchmaking

لو السيرفر = مملكة واحدة كبيرة (خريطة داخلية):
- 8 Regions تتنافس عليها التحالفات الكبرى
- Top alliances تتوزع على الجهات لتجنب dead side

- شجّع التوسع عبر Pass quests
